Kia ora, I'm Western. I'm Māori, from Aotearoa New Zealand, and I live in Amsterdam, where I'm a cloud engineer at [Sensys Gatso Software](https://www.sensysgatso.com/).

The [reflections](/reflections/) are a curated collection of things I've built, learnt or found interesting, and the best place to get a feel for how I think.

## What I do

I've worked in DevOps and infrastructure for over {{< years-experience >}} years. To me the job is about helping developers move code to production in the fastest, safest, most reliable way possible. In practice that means infrastructure as code with Terraform, GitOps with [Argo CD](https://argo-cd.readthedocs.io), CI/CD pipelines, Kubernetes on AWS and Google Cloud, observability, and the security controls that sit underneath all of it.

I've been the solo DevOps engineer embedded in a product team, which meant feeling the same pain as the developers before trying to fix it. I wrote about how that differs from platform and infrastructure work in [DevOps vs Platform vs Infrastructure Engineer](/reflections/devops-vs-platform-vs-infrastructure-engineer/).

Lately I've been working out how to give AI coding agents more freedom without handing them the keys. I [sandboxed my own coding agent](/reflections/containerising-my-coding-agent/) in a dev container with an outbound firewall, and I write up what I learn at events like [AGNTCon + MCPCon Europe](/reflections/agntcon-mcpcon-europe-2026/).
